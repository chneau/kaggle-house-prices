# kaggle-house-prices

Kaggle House Prices: feature engineering, random forests and gradient boosting.

The notebooks in `code/` walk through data cleaning, feature engineering and model comparison on the Ames housing dataset. `input/` holds the competition data.

## Run

```bash
make run
```

`make run` starts a Jupyter container and exposes the notebook port; `make native` runs a local Jupyter installation instead. The Makefile also documents the Tensor and Spark variants.
